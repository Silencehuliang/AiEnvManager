# 直读直写真实配置,不做声明式接管

各宿主 CLI(ZCode/Codex/OpenCode/dsh)自身也会读写同一批配置文件,若本工具另立事实源,两边写入会互相覆盖。决定:**真实配置文件是唯一事实源**,工具直读直写、写回保留所有未知键、每次写前自动备份(保留最近 N 份,可回滚)。写回前做乐观并发校验(内容/mtime 与读入时一致,宿主运行中改动过则提示刷新而非覆盖)。写盘遵循**最小侵入**原则(cc-switch 先例):切换类操作只改 endpoint/key/model 等连接字段,plugins、hooks、MCP、注释一概不动,且不提供「删除当前活跃供应商」的操作,保证卸载本工具后四家宿主照常可用。拒绝 chezmoi/terraform 式的「工具 manifest 生成配置」方案,因为它与宿主自身的写入行为冲突,守恒成本高。

## Considered Options

- 声明式接管(工具 manifest 为事实源,生成真实配置):功能最强,但与宿主 CLI 自身写入冲突,否决。
- 直读直写 + 预设层(Profile 机制):v1 不做,列为后续演进;供应商档案库(ADR-0002)已覆盖最迫切的切换场景。
